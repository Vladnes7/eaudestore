## Решения
Этап 1 (бриф), ответы Влада:
- Целевое действие: заказ через Telegram (кнопка в карточке открывает Telegram с готовым текстом: товар, объём, цена). Оплаты на сайте нет.
- Каталог: полный на сайте (поиск, фильтры: бренд, объём, цена, наличие; карточка товара).
- 3D: один 3D-флакон в hero, вращается при скролле (Three.js / R3F); остальные страницы лёгкие.
- Тон/цвета: ЗАМЕНЕНО на палитру «Luxury / quiet luxury» (скриншот Влада, этап 3). Розовый неон отменён.
- Фото: генерируем/дорабатываем отдельно (Влад).
- Тема: тёмная тёплая основа (шоколад) + кремовые/шампань блоки, золото как акцент. Чистый белый НЕ используем (Влад: пустой, некрасочный).
- Палитра (hex, из референса): Champagne #D8C5A5, Warm Ivory #F4EFE7, Muted Taupe #A99482, Mocha #7E675A, Deep Chocolate #4A3428, Muted Gold #A68B5B. Для глубины фона добавим более тёмный оттенок шоколада (~#2A1C15) — на согласование.
- Стиль: quiet luxury, timeless, refined. Свечение — тёплое золотое/шампань, не неон.
- Hero: на весь экран сгенерированная картинка парфюма, на загрузке плавно по очереди появляются самые хитовые флаконы (из витрины 343). Далее 3D-флакон, вращающийся на скролле.
- Каталог: два раздела — (1) Витрина: 343 нишевых со старого сайта (полные карточки, фото, ноты); (2) Прайс: 45 657 позиций из Google-таблицы. Обоим добавляем логотип бренда. Страницы брендов с логотипом.
- Анимации: «Вау» на hero и страницах брендов, средний уровень на каталоге.
- 3D-флакон: фирменный (без чужого бренда), генерируем картинку -> GLB (Higgsfield generate_3d) -> Three.js.
- Мини-приложение каталога Тимофея: встроить/перепривязать к сайту (источник товаров), ссылку/код Влад пришлёт.
- Страницы брендов: каталог по брендам, на странице бренда логотип + его ароматы; фильтры по мл/тестерам/наличию.
- Карточка аромата: красивое описание, ноты (ориентир — Fragrantica). Факт: в старом каталоге ноты есть у 323 из 343 карточек (плоским списком, без пирамиды верх/сердце/база).
- Данные каталога требуют чистки: 27 брендов, дубль «Filippo Sorcinelli»/«Filippo Sorchinelli», 3 товара без бренда, дубли коллекций.

## Находка: мини-приложение каталога (https://vladnes7.github.io/eaudestore-catalog/, репо Vladnes7/eaudestore-catalog)
